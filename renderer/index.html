Sauvegarde

Un seul fichier chiffré (AES-256) avec vos classes, notes, emploi du temps et cahier de texte. Il s’échange avec l’application du téléphone, dans les deux sens.

Créer une sauvegarde

Sans le mot de passe, la sauvegarde ne peut pas être ouverte : personne ne peut le retrouver pour vous. Pour la restaurer sur le téléphone, tapez le même mot de passe.

Restaurer une sauvegarde

Vient du téléphone ou d’un autre PC. Seul ce qui manque ici est ajouté : rien n’est écrasé.

Authenticator

Les codes à 6 chiffres de vos comptes (Massar, TGR…), comme Google Authenticator. Cliquez sur un code pour le copier.

Connexions

Votre identifiant et votre mot de passe pour chaque site : ils sont tapés pour vous quand la page de connexion s’ouvre. Ils ne sont jamais tapés sur une page qui n’appartient pas au site.

Livres

Vos livres scolaires, enregistrés dans l'application. Vous pouvez les lire sans internet.

Fichiers

Ce que vous téléchargez depuis les sites (Massar, Haraka…) est rangé ici, avec le bon nom et le bon type même quand le site se trompe.
